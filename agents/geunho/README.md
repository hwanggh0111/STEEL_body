  남은 구멍(2차 버그)을 찾는다. 시안 검사를 맡으면 판정만 보낸다.

## 지키는 것

1. **파일을 쥐기 전에 벼림에게 알린다.** 남이 쥔 파일(미커밋 `M` · `??`)은 안 건드린다
2. **커밋은 경로를 박는다** — `git commit -- <파일>`. 같은 트리에 남의 손이 있다
3. **고친 것은 되돌려-FAIL 까지 본다** — 고침을 빼면 자가 우는지 확인하고 원상 복구
4. **`main` 에 올리면 Render 가 배포한다.** 주인 말 없이 `main` 에 안 올린다 —
   그날의 보류 브랜치(`hold-MMDD`)로 올린다
5. 커밋은 근호가 판단한다(주인이 맡겼다). push · 배포는 주인 · 벼림 흐름을 따른다
6. 결과는 쉬운 말로, 근거는 `파일:줄` 로
