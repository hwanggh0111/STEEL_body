## ★ 주인 손이 필요한 것 (먼저 물을 것)

### 1. 라이브 옛 사진 줄이기 — 일꾼은 다 됐고 **아직 안 돌렸다**

```bash
cd backend
DATABASE_URL=<라이브> npm run shrinkphotos              # ★ 재기만 (아무것도 안 바꾼다)
DATABASE_URL=<라이브> npm run shrinkphotos -- --진짜로    # 줄여 담는다
npm run shrinkphotos -- --되돌리기 <photo-backup-*.json>  # 되돌린다
```

- **라이브 서버가 멎어 있어야 한다.** 떠 있으면 일꾼이 **시작하지 않는다**(두드려
  본다) — 서버가 사진 판을 램에 들고 있고 Postgres 에서는 바깥의 고침을 못 알아채서,
  그 서버가 사진 한 장을 저장하면 **줄인 것이 통째로 되돌아간다**
- 지금 라이브는 503(무료 시간 소진)이라 **돌리기 좋은 때**다
- 필요한 것: `DATABASE_URL` 을 **글자로** (캡처에서 읽지 않는다)
