# 폰 테스트 확인 목록 — 2026-09-17

9/16 에 붙인 것들은 **브라우저에서만** 봤다. 카메라 · 마이크 · 폰 사진 · 오프라인은
**실기기에서만 밝혀진다.** 이 문서는 폰을 손에 들고 순서대로 짚는 목록이다.

시작 전에 한 줄:

```
powershell -ExecutionPolicy Bypass -File scripts\phone-test.ps1 -Check   # 준비물만 확인
powershell -ExecutionPolicy Bypass -File scripts\phone-test.ps1          # 서버 + 터널 + APK
```

- **APK 를 반드시 새로 만든다.** 9/16 에 `AndroidManifest.xml` 에 CAMERA 권한을 넣었다 —
  지난 APK 로는 겹쳐 찍기가 안 된다 (스크립트가 알아서 새로 만든다)
- **터널 주소(https)로 들어간다.** 카메라 · 마이크는 https 에서만 열린다. LAN 주소(http)로는
  화면은 떠도 카메라가 안 열린다
- 자동 로그인은 꺼져 있다 — 폰에서 직접 로그인한다

## 1. 껍데기 · 길찾기 (6차에서 바뀐 자리)

- [ ] 아래 탭이 **오늘 · 운동 · 기록 · 몸** 넷이고 첫 칸 그림이 **사람 모양**인가
- [ ] 첫 탭 이름이 「오늘」인가 (「HOME」이 아니다)
- [ ] **안드로이드 뒤로 가기 단추** — 앞 화면이 있으면 앞으로, 첫 화면에서만 앱이 닫히는가
- [ ] 「몸」 탭의 갈래 줄(인바디 · 재는 도구 · 견주기)에서 **글자가 안 잘리는가**
- [ ] 「기록」 탭의 갈래 셋(달력 · 기록의 벽 · 통계)이 손가락으로 눌리는가

## 2. 오늘 탭

- [ ] 맨 위에 **「오늘 할 곳」** 카드 — 작은 몸에 달아오른 부위가 칠해져 있는가
- [ ] 그 카드를 누르면 **몸 지도**(`/map`)가 열리는가
- [ ] 오늘 적은 것이 있으면 **「오늘 결산 · 다시 보기」** 줄이 있고, 누르면 결산이 뜨는가

## 3. 몸 지도

- [ ] 앞모습 · 뒷모습 둘이 **폰 폭에 들어가는가** (좌우로 안 넘치는가)
- [ ] 몸을 누르거나 아래 줄을 누르면 그 부위가 **펼쳐지는가**
- [ ] 줄이 **손가락으로 겨냥되는가** (44px 로 잡아뒀다)
- [ ] 「○○ 운동 찾기」를 누르면 그 부위가 **검색된 채로** 운동 화면이 열리는가

## 4. 기록의 벽

- [ ] 판 열두 장이 폰에서 **세 줄로 잘 앉는가** (칸이 뭉개지지 않는가)
- [ ] **오늘 칸에 금색 테두리**가 있는가 (올해를 보고 있을 때)
- [ ] 판(달)을 누르면 **위 달력이 그 달로** 가고 화면이 위로 올라가는가

## 5. 운동 끝 결산

- [ ] 루틴 마지막 칸을 체크하면 **화면을 덮고** 뜨는가
- [ ] 큰 숫자가 **0에서 올라가는가**
- [ ] 오늘 한 것 목록 · 부위 딱지가 보이는가
- [ ] 「늘어졌나」 줄 — **안 나오는 것이 정상일 수 있다.** 기록이 셋 이상이고 첫 기록과
      마지막이 10분 넘게 벌어져야 잰다. 한꺼번에 적은 날은 일부러 아무 말도 안 한다

## 6. 겹쳐 찍기 ★ 오늘의 핵심

「몸 → 견주기」 → 전/후 사진 칸 아래 **「겹쳐 찍기」**.

- [ ] 처음 누를 때 **카메라 권한을 묻는가** (매니페스트 권한이 먹는지 여기서 밝혀진다)
- [ ] 카메라 그림이 보이는가 (검은 화면이면 실패)
- [ ] 지난 사진이 **반투명으로 겹쳐 보이는가** — 겹칠 사진이 없으면 안 겹치는 것이 맞다
- [ ] 겹친 정도 슬라이더가 움직이는가
- [ ] **찍은 것이 보이던 그대로인가** ★ — 위아래가 더 잘렸거나 좌우가 바뀌었으면 **적어둘 것**
- [ ] 「앞면으로 / 뒷면으로」가 바뀌는가
- [ ] 찍은 사진이 그 칸에 들어가고, 앱을 껐다 켜도 남아 있는가

## 7. 말로 적기

「운동」 탭에서 운동을 고르면 무게·세트·횟수 칸 아래.

- [ ] **단추가 보이는가** ← 이것 자체가 확인할 것이다.
      Web Speech 는 크롬 계열에만 있어서 **안드로이드 앱(웹뷰)에서는 안 보일 수 있다.**
      안 보이면 실패가 아니라 «웹뷰에는 없다»는 뜻이다 — 그때는 폰 크롬으로 터널 주소를
      열어서 다시 본다
- [ ] 보인다면: 누르고 「팔십 여덟개」 → **「이렇게 들었어요 · 80kg · 8회」**가 뜨는가
- [ ] 「이대로 넣기」를 눌러야 칸에 들어가는가 (저절로 저장되면 안 된다)

## 8. 사진 줄이기 (여태 미확인)

- [ ] 「몸 → 견주기」에서 **폰 앨범의 큰 사진(3MB+)** 을 고른다
- [ ] 거절당하지 않고 올라가는가 · 「올리기 좋게 줄였어요」가 뜨는가

## 9. 홈페이지 (/site)

폰 크롬에서 **로그아웃 상태로** 터널 주소 + `/site`.

- [ ] **로그인 없이 열리는가**
- [ ] 찾기 칸에 「벤치」를 치면 **그 자리에서 결과가 뜨는가** (로그인 화면으로 안 튀는가)
- [ ] 바로가기 여섯 · 소식 다섯 줄이 보이는가
- [ ] 상자들이 폰에서 **한 줄로** 흐르는가

## 10. 관리자 사진

관리자로 로그인 → 관리자 → **홈페이지 사진**.

- [ ] 폰 사진을 골라 올라가는가 (여기서도 줄이기가 돈다)
- [ ] 설명 붙이기 · 차례 바꾸기 · 내리기가 되는가
- [ ] `/site` 의 「사진」 칸에 나오고, 눌러서 크게 보이는가

## 11. 오프라인 (지하에서 쓰는 앱이니까)

- [ ] 비행기 모드로 바꾸고 운동을 하나 적는다 → **저장되는가**
- [ ] 화면에 「아직 안 올라감」 표시가 되는가
- [ ] 비행기 모드를 끄면 **저절로 올라가는가** · **두 번 올라가지 않는가**

## 안 되는 것이 나오면

화면 이름 · 무엇을 눌렀나 · 무엇이 나왔나 세 줄만 적어두면 된다.
카메라·마이크는 **되는 폰과 안 되는 폰이 갈릴 수 있어서**, 어떤 폰인지(기종 · 안드로이드
버전)도 같이 적어두면 좋다.

끝나면 스크립트가 띄운 창 셋(backend · frontend · cloudflared)을 닫으면 다 내려간다.
**터널은 개발 서버를 밖에 여는 것이라 테스트가 끝나면 바로 닫는다.**
