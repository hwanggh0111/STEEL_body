먼저 이것부터. 사람이 눌러보기 전에 기계가 볼 수 있는 것은 기계가 본다.

```bash

cd backend  && npm start          # (다른 창)
cd backend  && npm run smoke      # 서버가 실제로 답하는지 한 바퀴
cd backend  && npm run seed       # 화면을 채울 석 달치 시연 데이터
```

시연 계정 — **seed@demo.local / seed12345**

## 1. 눈으로 봐야 하는 것 (기계가 못 본다)

### 사진 줄이기 — **제일 확인이 필요하다**

오늘 넣은 것 중 **브라우저가 있어야만 돌아가는 유일한 코드**다. node 로는 캔버스가
없어 못 돌려봤다.

1. 고객센터 위쪽 프로필 → 사진 바꾸기 → **폰 카메라로 찍은 사진**(3MB 이상)을 고른다
2. 올라가야 한다. 예전에는 「1.5MB 이하만 가능해요」로 튕겼다
3. 비교 화면 → 전 · 후 사진도 같은 것을 해본다.
   줄였으면 **「사진 저장! (올리기 좋게 줄였어요)」** 라고 뜬다

안 되면 → `frontend/src/data/shrinkImage.js`. 못 줄이면 원본을 그대로 올리게 돼 있어서,
그 경우 예전처럼 한도 안내가 뜬다.

### 관리자 화면 색

보안 화면 셋의 색을 앱 토큰으로 바꿨다. **초록 · 빨강 · 노랑이 앱의 다른 곳과 같아야
한다.** 어딘가 글자가 안 보이거나 배경과 같은 색이면 토큰을 잘못 짚은 것이다.
제목도 `SECURITY DASHBOARD` → **「보안 현황」**.

### 자동완성 키보드

기록 화면에서 운동명을 치면 목록이 뜬다.

- **↓↑** 로 옮겨진다 (짚인 줄의 배경이 바뀐다)
- **Enter** 로 골라진다
- **아무것도 안 골랐을 때의 Enter 는 그대로 저장**이어야 한다
- **Esc** 로 닫힌다
- 마우스로 짚으면 그 줄이 골라진 자리가 된다 (키보드와 같은 곳을 가리킨다)
- 마우스로 눌러도 **매번** 골라져야 한다 (예전에는 가끔 샜다)

## 2. 화면에서 확인할 것

### 홈

- 「최근 체중」 카드에 **Tab 으로 닿고 Enter 로 들어가진다**
- 주간 요약 — 시연 데이터로 **주 연속 5주**가 나온다 (12주 중 한 주를 쉬게 넣었다)
- 할 말에 **「등이 2주째 없어요」** 처럼 조사가 맞다 (예전엔 「등가」)

### 기록

- 운동명에 **띄어쓰기만** 넣고 저장 → 막힌다
- 세트에 **0** → 「1 이상의 정수여야 해요」 (예전엔 「필수에요」)
- 세트에 **2.5** → 막힌다
- 무게에 **-50** → 막힌다. 「맨몸」 · 「20kg」 은 그대로 된다

### 인바디 · 측정

- 인바디 그래프가 시연 데이터로 그려진다 (7건, 체중이 조금씩 줄어드는 모양)
- 측정 화면의 칸이 다 차 있다 (둘레 · 1RM · 체력 · 유연성 · 어깨)
- 내보내기 셋(운동 · 인바디 · 측정)이 CSV 로 받아진다

### 루틴

- 시연 루틴 셋이 보인다. 「이 루틴으로 운동 시작」 → 기록 화면으로 간다
- 루틴명에 띄어쓰기만 넣고 만들기 → 막힌다

### 고객센터

- **자주 묻는 것이 열다섯 개**다. 제보함 앞의 단추는 **여섯 개**만 보이고
  나머지는 「모두 보기」에 있다
- 제보 본문에 `---` 구분선을 넣어도 **그냥 저장된다**
  (오늘 아침까지는 이 줄 하나로 계정이 정지될 수 있었다)

### 관리자

- 보안 점검을 돌리면 **Content-Security-Policy** 와 **Permissions-Policy** 가
  목록에 있고 둘 다 통과다
- AI 관리자 · 보안 현황의 숫자가 0 이 아니라 실제 값이다

## 3. 겪기 어려운 것 (돼 있다는 것만 알아두면 된다)

이건 일부러 만들기 번거롭다. 고쳤다는 사실만 적어둔다.

| 무엇 | 어떻게 확인하나 |
|---|---|
| **켜둔 채 자정을 넘기면 어제 날짜** | 폰 날짜를 다음 날로 바꾸고 앱으로 돌아오면 오늘로 맞춰진다 |
| **주 연속이 월요일마다 0** | 위와 같은 방법. 「주 연속」이 그대로 있어야 한다 |
| **로그아웃해도 앞 사람 사진** | 로그아웃 → 다른 계정 로그인 → 프로필과 전·후 사진이 비어 있어야 한다 |
| **다른 기기에서 지운 사진** | A 에서 지우고 B 를 새로고침하면 B 에서도 없어진다 |
| **「답변이 왔어요」가 안 뜸** | 로그아웃 후 다른 계정으로 제보하고 답을 달면 표시가 뜬다 |
| **쿠키 막힌 브라우저에서 갱신 고리** | 시크릿 창에서 쿠키를 막고 써본다 |
| **로그인 유지 열쇠 평문 저장** | `backend/ironlog.json` 의 `refreshTokens` 에 `token_hash` 만 있다 |
| **사진이 기록과 같은 파일** | 사진을 올린 뒤 `backend/photos.json` 이 생기고 `ironlog.json` 은 작게 남는다 |

## 5. 아직 못 하는 것

- **Render 배포** — 내가 여는 길이 없다
- **VAPID 열쇠** — 없어서 운동 알림이 안 나간다. 켜기 단추를 아예 안 그린다
- **소셜 열쇠** — 안 붙은 곳은 눌러도 안 된다
- **SMTP** — 제보 알림 메일도 비밀번호 찾기 메일도 안 나간다

배포한 뒤에는 스모크를 그쪽으로 돌릴 수 있다.

```bash
cd backend && SMOKE_BASE=https://<주소>/api npm run smoke -- --keep
```

`--keep` 을 주면 만든 계정이 남는다 (원격은 파일을 못 지운다). 관리자 화면에서 지운다.

## 정리용

```bash
cd backend && npm run seed:clear    # 시연 데이터 지우기  (서버를 내리고)
cd backend && npm run smoke:clean   # 쌓인 검사 계정 지우기 (서버를 내리고)
```

**서버를 내리고 하는 이유** — 서버는 DB 를 램에 들고 있다가 나중에 파일로 흘린다.
켜진 채로 파일을 고치면 옛 내용이 덮어쓴다. 오늘 이것 때문에 두 번 헛돌았다.
