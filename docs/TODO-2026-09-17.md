## A. 길찾기를 마저 끝낸다 ★ 내일의 중심

`data/navItems.js` 에 **우리가 스스로 적어둔 약속**이 있다:

> **옛 화면 둘은 되돌릴 수 있게 남겨둔다** — 새 「운동」이 아직 못 하는 것이 있다
> (고치기 · 지우기 · 지난 날짜에 적기). **5차를 마치면 이 둘을 걷는다.**

5차도 6차도 지났는데 아직 그대로다. 그래서 지금 앱에는 **같은 일을 하는 길이 두 벌**이다 —
탭바의 「운동」과 서랍의 「옛 기록 · 옛 루틴」. 쓰는 사람은 어느 쪽이 진짜인지 모른다.
**미룰수록 두 벌인 채로 굳는다.**

순서대로 한다:

1. **새 「운동」 탭에 셋을 넣는다**
   - **고치기** — 오늘 적은 것 줄을 눌러 무게·세트·횟수를 고친다
   - **지우기** — 잘못 적은 줄을 지운다 (한 번 묻는다)
   - **지난 날짜에 적기** — 어제 것을 오늘 적는 일이 실제로 잦다.
     지금은 `payload.date` 가 `today` 로 박혀 있다 (`TrainPage.jsx` 의 저장 부분)
2. **루틴 고치기**가 옛 화면(`RoutinePage`)에만 있다. 서버에는 `PUT /my-routines/:id` 가
   이미 있으니 화면만 붙이면 된다
3. 셋이 되면 **서랍에서 두 줄을 걷는다** (`data/navItems.js` 의 `/workout` · `/routine`).
   라우트는 **남겨둔다** — 북마크·홈 화면 바로가기로 들어오는 사람이 있다
4. 걷은 뒤 확인할 검사: `npm run check` 의 **「같은 자리로 가는 길은 세 화면이 같은
   그림을 쓴다」** 와 **「소개가 없는 자리를 가리키지 않는다」** (탭바 · 홈 검색 ·
   고객센터 소개가 서로 어긋나면 여기서 걸린다)

## B. 작고 값이 큰 것 — 오전에 셋 다 끝난다

- **화면 켜두기를 운동에도.** wake lock 이 **기능성운동 화면에만** 있다
  (`HomeworkoutPage.jsx` 161줄). 정작 루틴 진행·휴식 타이머 중에는 세트 사이에 화면이
  꺼져서 매번 깨워야 한다. **코드가 이미 앱 안에 있으니 옮기면 된다**
- **사진을 내보내기에 넣는다.** CSV 로 운동·인바디·측정은 빼는데 **몸 사진은 못 챙긴다.**
  계정 삭제는 30일 유예인데, 그 안에 사진을 못 가져가면 그냥 사라진다
- **검색 화면이 `?q=` 를 못 받는다.** 다른 화면에서 검색어를 들고 보내도 빈 화면이 열린다.
  홈페이지(`/site`)는 그 화면을 안 거치게 돌려놨지만 앱 안은 그대로다

## C. 새로 붙일 것 — 하루씩

- **가져오기(복원).** 내보내기는 있는데 **되돌릴 길이 없다.** 기기를 바꾸거나 계정을
  새로 만들면 CSV 가 있어도 못 넣는다. DB 가 날아갈 위험이 남은 지금은 더 크게 걸린다
- **식은 부위 알림.** 지금 알림은 「정한 요일·시각」과 「오래 쉬면 한 번」이 전부다.
  **몸 지도와 이으면 이 앱만의 알림이 된다** — 「등이 7일째 식었어요」.
  다른 앱은 「운동할 시간이에요」밖에 못 보낸다
- **목표.** 체중 목표도 주 몇 회 목표도 없다. 「남과 안 겨룬다」와 부딪히지 않는다 —
  겨루는 상대가 자기 자신이다. 1년 벽 · 주간 요약에 이어붙일 자리가 이미 있다
- **앱 잠금(PIN 네 자리).** **몸 사진이 들어 있는 앱**인데 폰을 잠깐 빌려주면 다 보인다

## D. 결정이 나와야 움직이는 것 — 내 손 밖

**개발이 끝나고 「배포하자」 할 때 꺼낸다.** 그때 바로 설명할 수 있게 정리는 해뒀다.

- **DB 가 살아남게** — Render 무료 플랜은 디스크를 못 붙여 재시작마다 JSON DB 가 날아간다.
  길은 둘: 월 $7 유료 플랜, 또는 **무료 Postgres 에 파일 둘(본체·사진)을 그대로 얹기**
  (전면 이사가 아니라 `db.js` 의 load/save 만 갈아끼우는 일 — 하루 안쪽)
- **SMTP** — 없으면 비밀번호를 잊었을 때 되찾을 길이 없다. 지메일 앱 비밀번호면 된다
- 스토어($25 · 평생 1회)는 나중에 붙여도 된다

## E. 눈으로만 확인되는 것 — 폰에서 한 바퀴

`scripts/phone-test.ps1` 한 줄이면 서버 둘 + 터널 + APK 까지 만들어진다.

- **겹쳐 찍기** — 카메라·캔버스는 node 에 없다. 계산(자르기·기준 사진)은 검사로 덮었지만
  실제 촬영은 봐야 한다. 안드로이드 앱에서는 **매니페스트에 넣은 CAMERA 권한**이
  실제로 먹는지 같이 본다
- **말로 적기** — Web Speech 는 크롬 계열에만 있다. **안드로이드 웹뷰에서는 단추가 안
  뜨거나 안 될 가능성이 크다.** 안 되면 그때 길을 따로 본다
- **사진 줄이기**(`shrinkImage`) — 폰 사진(3MB+)으로 한 번 올려봐야 한다. 여전히 미확인이다
