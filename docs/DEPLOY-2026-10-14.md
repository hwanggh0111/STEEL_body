## 1. Postgres 주소 — 이게 없으면 배포해도 기록이 사라진다

무료 Neon(<https://neon.tech>) 등에서 데이터베이스를 하나 만들고 **연결 주소**
(`postgresql://...`)를 받습니다.

**왜 꼭 필요한가** — Render 무료 판은 디스크를 못 붙입니다. 파일로 두면
**배포할 때마다 · 잠들었다 깰 때마다 `blackiron.json` 이 통째로 사라집니다.**

주소가 생기면 **처음 한 번은 서버가 쓰던 파일을 그대로 옮겨 올립니다**
(이미 들어 있으면 안 덮습니다). 주시면 제가 **진짜 Postgres 로 한 바퀴** 돌려보고
옮겨지는 것까지 확인합니다 — 지금까지는 **가짜 Postgres 로만** 봤습니다.

## 2. 구글 콘솔 — **확인만** 하면 됩니다

<https://console.cloud.google.com/apis/credentials> → 해당 OAuth 클라이언트 →
**승인된 리디렉션 URI**

```
이미 들어 있어야 하는 것   https://steel-body.onrender.com/api/oauth/google/callback
개발용 (그대로 둔다)      http://localhost:4000/api/oauth/google/callback
```

**주소를 콘솔에 맞췄으므로 고칠 것이 없습니다.** 위 줄이 정말 들어 있는지만
한 번 보고 나오시면 됩니다 — 한 글자라도 다르면 구글이 `redirect_uri_mismatch` 로
막습니다.

> 배포본은 화면과 서버가 같은 주소라 위 한 줄이면 됩니다.

## 4. Render 대시보드에 손으로 넣을 값

`render.yaml` 에 **자리는 이미 다 있습니다**(`sync: false`). 값만 채우면 됩니다.
`NODE_ENV` · `TRUST_PROXY` · `JWT_SECRET` · `FRONTEND_URL` · `BACKEND_URL` 은
`render.yaml` 이 알아서 넣습니다.

| 키 | 어디서 가져오나 |
|---|---|
| `DATABASE_URL` | 1번에서 만든 주소 |
| `ADMIN_EMAIL` | ⚠ **반드시 gmail** — 예전에 `gmali` 오타로 계정이 갈라졌습니다 |
| `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET` | 내 컴퓨터 `backend/.env` 에 있는 그 값 |
| `NAVER_CLIENT_ID` · `NAVER_CLIENT_SECRET` | 3번에서 **재발급한** 새 값 |
| `SMTP_HOST` · `SMTP_PORT` · `SMTP_USER` · `SMTP_PASS` · `SMTP_FROM` | `backend/.env` 의 그 값 (지메일 앱 비밀번호) |
| `VAPID_PUBLIC_KEY` · `VAPID_PRIVATE_KEY` · `VAPID_SUBJECT` | `backend/.env` 의 그 값 — **새로 만들지 마세요.** 바꾸면 지금 있는 알림 구독이 전부 끊깁니다 |

> `backend/.env` 는 git 에 안 올라갑니다. 그 파일을 열어 값을 그대로 복사해
> Render 의 `Environment` 탭에 Key / Value 로 넣으면 됩니다.

## 5. 배포 뒤에 바로 볼 것

| 보는 것 | 어떻게 |
|---|---|
| 서버가 떴나 | `https://steel-body.onrender.com/api/health` 가 200 |
| 소셜 둘이 켜졌나 | `/api/oauth/providers` 가 `{"google":true,"naver":true}` |
| 구글 로그인 | 실제로 눌러 들어와 본다 |
| 네이버 로그인 | 실제로 눌러 들어와 본다 |
| 기록이 남나 | **한 번 재배포한 뒤** 기록이 그대로인지 — 이게 Postgres 가 붙었는지 보는 진짜 시험 |
| 가입 메일 | 번호가 오는지 (SMTP) |

> **재배포 중에 소셜 로그인을 눌러도 괜찮습니다** (10/13 에 고쳤습니다). state 를
> 서버 메모리에 담던 동안은 배포로 서버가 다시 뜨거나 15분 잠들었다 깨면 그 사이에
> 누른 사람이 전부 `invalid_state` 로 떨어졌습니다 — 지금은 **서명한 쿠키**에 담아서
> 서버가 새로 떠도 이어집니다.
