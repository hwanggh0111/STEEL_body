## 1. 내가 못 하는 것 — 눈과 손이 필요하다

| 무엇 | 어떻게 | 왜 값으로는 못 보나 |
|---|---|---|
| **폰에서 겹쳐 찍어보기** | `scripts/phone-test.ps1` → 몸 → 체형 → 「겹쳐 찍기」 | 카메라는 **https 나 localhost 에서만** 열린다. 겹친 사진 위에 몸을 맞추는 일은 숫자로 확인할 수가 없다 (체형 04 의 마지막 칸) |
| **기울기가 고쳐진 것 보기** | 같은 화면에서 사진 한 장 | 9/30 낮 전에는 똑바로 서도 「어깨선이 180도」가 붙고 **실루엣이 늘 최대로 기울어** 있었다. 이제 안 붙어야 맞다 |
| **회복 시간 재보기** | 설정함에서 **숨 보고 쉬기** 켜기 → **몸 → 회복** → 「숨 회복 지금 재보기」 (홈트의 「쉬는 화면 미리 보기」에도 같은 단추가 있다) | 마이크를 켜고 **실제로 숨이 차야** 값이 나온다. 「지난 번보다 빨라졌어요」는 **다른 날에 같은 동작을 또** 해야 나온다 |
| **Render 배포** | 근호 계정으로만 된다 | 내가 손댈 수 있는 자리가 아니다 |

## 2. 열쇠 셋 — 없으면 그 기능만 조용히 빠진다

서버가 뜰 때마다 스스로 말한다. **앱은 그대로 돈다** — 없는 것을 있다고 안 한다.

| 열쇠 | 없으면 | 어디에 넣나 |
|---|---|---|
| **VAPID** | 운동 알림이 안 나간다 (스케줄러도 안 뜬다) | `.env` · Render 환경변수 |
| **소셜 로그인** | 구글 단추가 안 나온다 (이메일 로그인만) | `docs/google-login-setup.md` 에 절차가 있다 |
| **SMTP** | 메일로 가는 것(코드 · 비밀번호 찾기)이 안 나간다 | `.env` |

  운영 전에 비울지 정해야 한다. **제보와 달리 사람이 보낸 것이 아니라** 앱이 스스로
  적은 것이라 관리자 화면의 할 일로는 안 보인다.
- **헬스장 운동에도 숨 보고 쉬기** — 9/29 에 「홈트에만 있다」고 이름을 사실에 맞췄다.
  붙이는 것은 따로 정할 일로 남겨뒀다.

## 4. 알고 두는 것 (버그가 아니다)

- **`npm run smoke` 를 연달아 여러 번 돌리면 몇 건이 429 로 실패한다.** `/auth/delete`
  와 로그인이 15분 제한을 쓰기 때문이다. 검사가 「기다리지 않고 진짜 실패로 보이게」
  두기로 한 것이라 그대로 뒀다 — **한 번만 돌리면 전부 통과한다.**
- **파일을 직접 고칠 때는 서버를 내리는 것이 여전히 안전하다.** 9/30 부터 서버가 바깥의
  고침을 읽어 맞추지만(`npm run sync` 가 그것을 본다), 그것은 **안 쓴 것이 없을 때만**
  이다. 저장이 도는 중이면 램이 이긴다 — 그때는 서버가 그렇게 말한다.
