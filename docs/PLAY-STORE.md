## 1. 다시 뽑을 때

```
cd frontend
npm run aab     # 플레이스토어 업로드용 (.aab)
npm run apk     # 폰에 직접 깔아보는 용 (.apk)
```

**`frontend/android/local.properties` 를 만들지 말 것.** SDK 경로에 한글(`케빈12`)이
들어 있는데 Gradle 은 그 파일을 ISO-8859-1 로 읽어서 경로가 깨진다 — R8 단계에서
「파일 이름, 디렉터리 이름 또는 볼륨 레이블 구문이 잘못되었습니다」로 멎는다.
`scripts/build-android.mjs` 가 그 파일이 있으면 아예 멈춘다.

## 2. 열쇠 — **잃어버리면 업데이트를 영영 못 올린다**

```
frontend/android/blackiron-upload.jks        열쇠 (깃에 안 들어간다)
frontend/android/keystore.properties         비밀번호가 적혀 있다 (깃에 안 들어간다)
```

둘 다 `.gitignore` 안이다. **이 PC 가 죽으면 같이 죽는다.** USB 든 구글드라이브 든
깃 아닌 곳에 한 벌 떠둘 것. (플레이 앱 서명을 켜두면 업로드 열쇠는 나중에 구글에
요청해 바꿀 수 있지만, 켜는 것도 첫 업로드 때 한 번뿐이다 — 아래 3번에서 켠다.)

## 4. 스크린샷 — 유일하게 직접 찍어야 하는 것

**폰 2장 이상**이 필수다 (16:9~9:16 · 짧은 쪽 1080px 이상 권장).

제일 빠른 길: `app-release.apk` 를 폰에 옮겨 깔고, 쓰면서 찍는다.
찍을 자리 넷을 고르면 이 앱이 뭘 하는지 설명 없이 읽힌다.

| 순서 | 화면 | 왜 |
|---|---|---|
| 1 | 오늘 (`/home`) | 첫인상. 오늘 뭘 할지가 보인다 |
| 2 | 운동 (`/train`) 기록 중 | 이 앱의 본체 |
| 3 | 기록 (`/history`) 의 연간 벽 | 쌓인다는 것이 한 장으로 보인다 |
| 4 | 몸 지도 (`/map`) | 다른 앱에 없는 것 |

## 5. 데이터 보안 설문 — `/privacy` 와 **답이 같아야 한다**

다르면 반려된다. 방침에 적은 그대로 답한다.

| 묻는 것 | 답 |
|---|---|
| 데이터를 모으나 | 예 |
| 이름/이메일 | 예 — 계정 관리 · 필수 |
| 사진 | 예 — 앱 기능 · 선택 (겹쳐 찍기를 쓸 때만) |
| 건강·피트니스 | 예 — 앱 기능 · 필수 |
| 기기 ID / 접속 기록 | 예 — 사기 방지 · 필수 |
| **앱 정보 및 성능 → 비정상 종료 로그 · 진단** | **예 — 분석/앱 기능 · 필수** |
| 기타 사용자 콘텐츠 (고객센터에 적어 보낸 글) | 예 — 고객 지원 · 선택 |
| 제3자에게 **공유**하나 | 아니요 (맡기는 곳은 공유가 아니다) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제를 요청할 수 있나 | 예 — 앱 설정에서 직접 지운다 |

**계정 삭제 주소**를 따로 묻는다 → `https://steel-body.onrender.com/privacy`
(그 장의 "직접 할 수 있는 것" 에 길이 적혀 있다)

> **「비정상 종료 로그」 줄은 10/13 에 더했다.** 화면이 터지면 앱이 서버로 한 줄을
> 보낸다(`POST /api/client-errors` — 메시지 · 터진 자리 앞부분 · 어느 화면 ·
> 브라우저). 사람이 적은 글이나 기록은 안 붙이지만, **보내고 있으면 적어야 한다.**
> 방침(`/privacy`)에도 같이 적었다.
>
> 방침과 실제가 어긋나는 것을 사람이 기억하지 않아도 되게 **검사를 붙였다** —
> `npm run privacy` (`npm run check` 에 걸려 있다). 꺼진 소셜 로그인의 이름이
> 방침에 남아 있는지, 서버가 받고 있는 것이 방침에 적혀 있는지 본다.
> 10/13 에 그 검사가 **`카카오`** 를 잡았다 (10/7 에 걷어낸 것이 방침에 남아 있었다).

## 7. 걸릴 만한 것

- **심사 기간** — 첫 앱은 보통 며칠, 길면 2주까지 간다. 10/14 배포에 맞추려면
  **서버 배포와 동시에 올려야** 한다
- **무료 Render 는 15분이면 잠든다** — 심사자가 열었을 때 30초쯤 흰 화면이면
  "작동하지 않음" 으로 반려될 수 있다. 심사 기간에는 유료로 올리거나
  깨우는 핑(ping)을 걸어둘 것
- **소셜 로그인** — 네이버는 아직 `개발 중` 이라 멤버만 들어온다. 심사자는
  **이메일 가입**으로 들어가므로 막히진 않지만, 심사 메모에 시험용 계정을 적어주면 빠르다
- ~~**`invalid_state`**~~ — **10/13 에 고쳤다.** state 를 서버 메모리의 Map 에
  담던 것을 **서명한 쿠키**로 옮겼다. Render 가 자다 깨도 · 배포로 다시 떠도
  소셜 로그인이 그대로 이어진다 (`npm run oauth` 가 「서버가 다시 떠도
  로그인이 이어지는가」로 돌려본다)
