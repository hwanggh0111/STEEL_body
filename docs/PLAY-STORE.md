## 1. 다시 뽑을 때

```
cd frontend
npm run aab     # 플레이스토어 업로드용 (.aab)
npm run apk     # 폰에 직접 깔아보는 용 (.apk)
```

**`frontend/android/local.properties` 를 만들지 말 것.** SDK 경로에 한글(`케빈12`)이
들어 있는데 Gradle 은 그 파일을 ISO-8859-1 로 읽어서 경로가 깨진다 — R8 단계에서
「파일 이름, 디렉터리 이름 또는 볼륨 레이블 구문이 잘못되었습니다」로 멎는다.
`scripts/build-android.mjs` 가 그 파일이 있으면 아예 멈춘다.

## 5. 데이터 보안 설문 — `/privacy` 와 **답이 같아야 한다**

다르면 반려된다. 방침에 적은 그대로 답한다.

| 묻는 것 | 답 |
|---|---|
| 데이터를 모으나 | 예 |
| 이름/이메일 | 예 — 계정 관리 · 필수 |
| 사진 | 예 — 앱 기능 · 선택 (겹쳐 찍기를 쓸 때만) |
| 건강·피트니스 | 예 — 앱 기능 · 필수 |
| 기기 ID / 접속 기록 | 예 — 사기 방지 · 필수 |
| **앱 정보 및 성능 → 비정상 종료 로그 · 진단** | **예 — 분석/앱 기능 · 필수** |
| 기타 사용자 콘텐츠 (고객센터에 적어 보낸 글) | 예 — 고객 지원 · 선택 |
| 제3자에게 **공유**하나 | 아니요 (맡기는 곳은 공유가 아니다) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제를 요청할 수 있나 | 예 — 앱 설정에서 직접 지운다 |

**계정 삭제 주소**를 따로 묻는다 → `https://steel-body.onrender.com/privacy`
(그 장의 "직접 할 수 있는 것" 에 길이 적혀 있다)

> **「비정상 종료 로그」 줄은 10/13 에 더했다.** 화면이 터지면 앱이 서버로 한 줄을
> 보낸다(`POST /api/client-errors` — 메시지 · 터진 자리 앞부분 · 어느 화면 ·
> 브라우저). 사람이 적은 글이나 기록은 안 붙이지만, **보내고 있으면 적어야 한다.**
> 방침(`/privacy`)에도 같이 적었다.
>
> 방침과 실제가 어긋나는 것을 사람이 기억하지 않아도 되게 **검사를 붙였다** —
> `npm run privacy` (`npm run check` 에 걸려 있다). 꺼진 소셜 로그인의 이름이
> 방침에 남아 있는지, 서버가 받고 있는 것이 방침에 적혀 있는지 본다.
> 10/13 에 그 검사가 **`카카오`** 를 잡았다 (10/7 에 걷어낸 것이 방침에 남아 있었다).

## 5-1. 건강연동 — **첫 출시에 넣을지 말지 먼저 정한다** (2026-10-16)

인바디 적는 자리의 「건강 앱에서 가져오기」다. 헬스 커넥트에서 **체중 · 체지방률
둘만** 읽어 입력칸을 채운다(골격근량은 거기 있는 값이 다른 것이라 안 가져온다).

**이것이 켜져 있으면 심사가 하나 더 붙는다** — 건강 권한을 적은 앱은 구글의
**건강 앱 선언 양식**을 내야 하고, 방침에 그 항목이 따로 적혀 있어야 한다
(`/privacy` 의 「건강 앱에서 가져오는 것」 칸이 그것이다). 승인까지 더 걸린다.

### 빼고 올리려면 (되돌리기 쉬움)

```
cd frontend
npm uninstall capacitor-health
npx cap sync android
```
그리고 `android/app/src/main/AndroidManifest.xml` 의 **「건강 앱 연동」 블록 둘**
(`activity`/`activity-alias` 와 `uses-permission` 묶음)을 지운다. 되돌리려면
`npm i capacitor-health` 하고 그 블록을 다시 넣으면 된다.

- **화면 쪽은 손댈 것이 없다** — `src/data/healthLink.js` 가 플러그인을 못 찾으면
  단추를 아예 안 그린다. 다른 화면은 아무 영향이 없다
- `variables.gradle` 의 `minSdkVersion = 26` 은 **헬스 커넥트 때문에 올린 것**이다.
  빼기로 하면 24 로 되돌려도 된다(안드로이드 7.0까지 깔린다)
- **방침은 그대로 둬도 된다** — 「직접 누르셨을 때만 읽습니다」이므로 거짓이 아니지만,
  기능이 없는 채로 두는 것이 싫으면 그 칸만 지운다

### 넣고 올리려면

| 묻는 것 | 답 |
|---|---|
| 건강 데이터를 읽나 | 예 — 체중 · 체지방률 (READ_WEIGHT · READ_BODY_FAT) |
| 쓰나(기록하나) | 아니요 — 읽기만 한다 |
| 왜 필요한가 | 체중계가 이미 잰 값을 인바디 기록에 손으로 옮겨 적지 않게 |
| 어디로 보내나 | 아무 데도. 저장을 누르면 이 앱의 인바디 기록이 된다(서버는 Render) |
| 광고에 쓰나 | 아니요 |
| 방침 주소 | `https://steel-body.onrender.com/privacy` (「건강 앱에서 가져오는 것」) |

권한이 **둘뿐인지**는 검사로 지킨다 — `npm run health`. 플러그인이 제 매니페스트에
열세 개를 다 적어두고 있어서, 그냥 두면 **동의 화면에 걸음수 · 심박 · 식사까지 뜬다**
(`tools:node="remove"` 로 열한 개를 지워뒀다).

  소셜 로그인이 그대로 이어진다 (`npm run oauth` 가 「서버가 다시 떠도
  로그인이 이어지는가」로 돌려본다)
