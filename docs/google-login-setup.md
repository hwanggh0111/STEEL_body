# 구글 로그인 켜기

**코드는 다 돼 있다. 남은 것은 열쇠뿐이다.**

2026-09-03 에 구글 로그인 길을 앞뒤로 다 읽고, **구글만 가짜로 세워 한 바퀴 돌려봤다**
(`cd backend && npm run oauth`). 처음 들어온 사람은 계정이 만들어지고 로그인 열쇠 셋을
받고, 두 번째부터는 바로 들어가고, 구글이 이메일을 안 주면 계정을 안 만든다 — **전부
통과한다.** 지금 안 되는 이유는 하나다: `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET`
이 없다.

열쇠가 없으면 로그인 · 회원가입 화면에 **구글 단추가 아예 안 나온다**
(`/api/oauth/providers` 가 `google:false` 를 준다). 서버도 뜰 때 그렇게 말한다:

```
[oauth] 소셜 로그인 열쇠가 하나도 없습니다. 이메일 로그인만 됩니다 (버튼은 안 나옵니다)
```

---

## 1. 구글에서 열쇠 만들기

<https://console.cloud.google.com/apis/credentials>

1. 프로젝트를 하나 만든다 (아무 이름이나)
2. **OAuth 동의 화면** — 사용자 유형 `외부`, 앱 이름 · 지원 이메일만 채우면 된다.
   - **범위(scope)** 는 `email` 과 `profile` 두 개다. 이 앱은 그 둘만 받는다
   - 테스트 상태로 두면 **테스트 사용자에 넣은 계정만** 로그인된다. 본인 계정을 넣어둔다
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션**
4. **승인된 리디렉션 URI** 에 아래를 넣는다. **한 글자도 다르면 안 된다** —
   구글이 `redirect_uri_mismatch` 로 막는다

| 언제 | 넣을 주소 |
|---|---|
| 내 컴퓨터에서 볼 때 | `http://localhost:4000/api/oauth/google/callback` |
| 배포한 뒤 | `https://<배포주소>/api/oauth/google/callback` |

> 화면(5173)이 아니라 **서버(4000)** 주소다. 화면의 구글 단추는 `/api/oauth/google` 로
> 가고, vite 가 그것을 4000 으로 넘긴다. 구글이 돌아오는 곳은 서버다.
> 배포하면 화면과 서버가 같은 주소라 위의 둘째 줄 하나면 된다.

5. 만들면 **클라이언트 ID** 와 **클라이언트 보안 비밀번호**가 나온다

## 2. 열쇠 넣기

**내 컴퓨터** — `backend/.env` 에 두 줄을 더한다 (이 파일은 git 에 안 올라간다):

```
GOOGLE_CLIENT_ID=<클라이언트 ID>
GOOGLE_CLIENT_SECRET=<클라이언트 보안 비밀번호>
```

서버를 다시 띄우면 `[oauth]` 줄이 사라지고 로그인 화면에 구글 단추가 나온다.

**배포한 뒤** — Render 대시보드의 Environment 에 같은 두 개를 넣는다
(`render.yaml` 에 자리는 이미 있다, `sync: false`).

## 3. 되는지 보는 법

```bash
cd backend && npm run oauth     # 구글 없이 길 전체를 한 바퀴 (열쇠 없어도 돈다)
curl -s localhost:4000/api/oauth/providers   # {"google":true, ...} 면 단추가 나온다
```

그다음은 눈으로 — 로그인 화면에서 구글 단추를 누른다.
**처음 들어오는 계정에서만** 「이름을 정하세요」가 한 번 나오고, 두 번째부터는 바로 홈이다.

## 막히면

| 화면에 나오는 말 | 뜻 |
|---|---|
| `구글 로그인은 아직 준비 중이에요` | 열쇠가 없다 (`GOOGLE_CLIENT_ID` 를 안 넣었다) |
| 구글이 `redirect_uri_mismatch` | 위 4번의 주소가 다르다. 끝의 `/api/oauth/google/callback` 까지 똑같아야 한다 |
| `로그인 링크가 만료됐어요` | `state` 는 한 번 쓰면 끝이다. 뒤로 가기나 지난 링크로 오면 이렇게 된다 — 다시 누르면 된다 |
| `구글 로그인에 실패했어요` | 열쇠 값이 틀렸거나 구글이 이메일을 안 줬다. 서버 로그의 `OAuth error:` 줄을 본다 |
| 단추가 안 보인다 | 열쇠가 없다. 위와 같다 |

## 나머지 소셜

네이버 · 페이스북 · 인스타그램도 **코드는 다 돼 있다.** 열쇠를 넣으면 단추가 저절로
나온다. 돌아오는 주소 규칙도 같다 (`/api/oauth/<이름>/callback`).
인스타그램만 환경변수 이름이 `INSTAGRAM_APP_ID` 다 (`CLIENT_ID` 가 아니다).
