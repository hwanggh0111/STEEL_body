## 2. 새 체계 — **값 → 자 → 손 → 라이브** 네 문

지금은 **손 → 자 → 라이브** 다. 앞에 문 하나를 세운다.

### 1문 · 값 — 고치기 **전에** 「고치는 것이 옳은가」를 수로 적는다 (새로 세우는 문)

세 줄이면 된다.

    ① 전제            무엇이 참이어야 이 변경이 값을 내는가
    ② 무엇으로 쟀나   그 전제를 어떤 수로 확인했나 (수를 못 적으면 그 자리가 위험한 자리다)
    ③ 접는 선         ①이 틀렸으면 그 자리에서 접는다 — 접는 것도 한 건이다

**굵은 것에만 세운다** — 새 기능 · 산출물이나 생성기가 바뀌는 것 · 100줄 넘는 것.
**버그 고치기에는 안 세운다**: 버그의 전제는 「깨져 있다」 하나고, 그건 이미 잰 것이다.

오늘 이 문이 서 있었다면 — 내 조각내기는 **0.06%** 에서 멎었고, 맵시의 44px 는
`globals.css:131` 을 **읽는 데서** 멎었다. 둘 다 손이 가기 전이다.

### 2문 · 자 — 정석이 오늘 세운 규칙을 그대로 쓴다

- **파일이 아니라 열쇠를 본다** (손이 옮겨가도 따라간다)
- **수가 아니라 규칙을 본다** (조각 1벌이든 21벌이든 따라간다)
- **자가 베낀 값은 전부 FAIL 감이다** — 상수 · 표본 · 수 · 파일 이름. 원본을 그 자리에서 읽는다
- **되돌려-FAIL 까지가 한 건이다** — 고쳐 놓고 PASS 를 보는 것으로 끝내면 자가 장식이 된다
- **못 세우는 것을 세운 척하지 않는다** — 판단이 필요한 것은 FAIL 이 아니라 **알림**으로
  둔다(정석이 `check-fontfeat` 를 그렇게 뒀다)

### 3문 · 손 — 누가 들고, 어떻게 담나

| | 몫 |
|---|---|
| **벼림** | 1차 고침 · `src/data` · `src/pages` 의 뿌리 |
| **정석** | 중대 · 2차 · 전수 · **자로 셀 수 있는 류** · 판정 |
| **맵시** | 꼴 · UI · **눈으로 판정하는 것** |

- **파일은 쥐기 전에 알린다** (오늘 셋 다 지켰다 — 이건 이미 서 있는 문이다)
- **커밋은 경로를 박는다** — `git commit -- <파일>`
- **`git checkout --` · `git stash` 금지** (11/9 에 남의 미커밋을 날렸다)
- **한 류가 수십 파일에 퍼진 것은 파일을 쥐지 말고 목록을 먼저 올린다** — 류 하나를
  한 사람이 한 커밋으로 쓸면 충돌이 아예 안 난다

### 4문 · 라이브 — 밀고 끝이 아니다

- 커밋 + **push** + **공지 산출물 넷** 까지가 한 건 (Render 는 얕은 클론이라 빌드 때
  다시 안 뽑는다)
- **`index.html` 이 그때 가리키는 조각**으로 받아 확인한다 (옛 조각 주소는 `immutable`
  이라 영영 200 으로 옛 코드를 보여준다)
- 사람 눈에 보이는 변화는 `refactor` 로 적지 않는다 (공지는 `feat`·`fix`·`perf` 만 담는다)
