# 화면 지도 — 어느 기능이 어디 있나

> 홈페이지(`/site`)에 적힌 말이 **앱의 어느 화면인지** 짚어둔 문서입니다. (2026-10-07)
>
> 주소는 앱 안에서 치는 것이고, 내 컴퓨터에서는 앞에 `http://localhost:5173` 을 붙입니다.
> 배포한 뒤에는 `https://<배포주소>` 를 붙입니다.

---

## 먼저 — 앱은 두 겹입니다

| | 주소 | 로그인 | 무엇 |
|---|---|---|---|
| **홈페이지** | `/site` | **필요 없음** | 아직 안 쓰는 사람에게 이 앱이 뭔지 말하는 자리 |
| **앱** | `/home` 등 | 필요함 | 실제로 운동을 적는 자리 |

홈페이지의 **「앱 열기」 · 「시작하기」 · 「가입하기」** 가 앱으로 들어오는 문입니다.

```
/site          홈페이지 (지금 보고 계신 그 글)
/login         로그인
/register      회원가입
/oauth/email   소셜로 들어왔는데 메일을 못 받았을 때 (인스타·X 용, 지금은 안 쓰임)
```

## 앱의 뼈대 — 아래 탭 넷

폰에서 화면 아래에 늘 붙어 있는 줄입니다. **늘 쓰는 것 넷**만 둡니다.

| 탭 | 주소 | 무엇을 하나 |
|---|---|---|
| **오늘** | `/home` | 오늘 할 것 · 목표 · 요약. 앱을 열면 여기부터 |
| **운동** | `/train` | **세트를 적는 자리.** 무게 · 횟수 · 쉬는 시간 |
| **기록** | `/history` | 지난 날들 — 달력 · 기록의 벽 · 통계 |
| **몸** | `/body` | 인바디 · 재는 도구 · 견주기 · 체형 · 회복 |

### 서랍 (머리의 내 계정 → 또는 PC 에서는 왼쪽 줄)

**가끔 쓰는 것**은 탭을 안 늘리고 서랍에 둡니다.

| | 주소 | 무엇 |
|---|---|---|
| 기능성운동 | `/homeworkout` | 기구 없이 하는 판 |
| 운동 알림 | `/reminders` | 언제 알릴지 |
| 부위 | `/parts` | 아픈 곳 · 이 운동이 어디를 달굴지 |
| 고객센터 | `/support` | 문의 · 공지함 |
| 관리자 | `/admin` | 관리자만 보입니다 |

### 머리의 기어(⚙)

| | 주소 |
|---|---|
| 설정함 | `/settings` |

## 홈페이지에 적힌 말 ↔ 실제 화면

홈페이지 글을 위에서부터 그대로 따라가며 짚습니다.

### 「보여주는 것」 — 몸 지도

> *최근에 자극한 곳이 금빛으로 달아 있고 날이 갈수록 식습니다*

**→ `/map`** (홈페이지의 **「내 몸 지도 보기」** 단추가 여기로 옵니다)

앱 안에서는 **「몸」 탭** 과 **「부위」**(서랍) 에서 같은 그림을 씁니다.
가슴 · 등 · 하체 · 어깨가 며칠 전에 했는지에 따라 색이 다릅니다.

### 「찾기」 — 운동 이름으로 찾아보기

> *운동 이름으로 찾아보기 · 찾기*

**→ `/search`**

홈페이지의 검색칸에 치고 **엔터를 누르면 첫 결과로 바로 갑니다.**
그 아래 바로가기 여섯은 이렇게 이어집니다.

| 홈페이지의 바로가기 | 가는 곳 |
|---|---|
| 몸 지도 | `/map` |
| 운동 기록 | `/train` |
| 기록의 벽 | `/history` (「기록의 벽」 갈래) |
| 인바디 | `/body` (「인바디」 갈래) |
| 운동 알림 | `/reminders` |
| 고객센터 | `/support` |

### 「소식」

> *공지함 › · 앱의 모든 화면을 다시 만들었습니다 …*

**→ `/support/notices`** (고객센터 안의 공지함)

홈페이지에는 **다섯 줄만** 보여주고, 「공지함 ›」을 누르면 전체가 나옵니다.
거기서 **전체 · 공지 · 새 기능 · 고침 · 빨라짐** 으로 갈라 볼 수 있습니다.

> 날짜 옆의 글들은 **커밋에서 저절로 올라옵니다.** 손으로 적지 않습니다.

### 「이 앱이 하는 것」 — 여섯 개

| 홈페이지의 말 | 실제 화면 | 주소 |
|---|---|---|
| **몸 지도** | 몸 지도 | `/map` |
| **운동 끝 결산** | 「운동」에서 **마칠 때 뜹니다** | `/train` |
| **1년 기록 벽** | 「기록」 탭 → **기록의 벽** | `/history` |
| **체형 읽기** | 「몸」 탭 → **체형** | `/body` |
| **회복 시간** | 「몸」 탭 → **회복** | `/body` |
| **횟수 세기** | 「운동」에서 **카메라를 켤 때** | `/train` |

세 개는 **자기 화면이 아니라 어떤 자리에서 일어나는 일**입니다 —
결산은 운동을 마칠 때, 횟수 세기는 폰을 세워두고 세트를 할 때,
기록의 벽은 「기록」 탭 안의 한 갈래입니다.

### 「안 하는 것」 — 다섯 개

화면이 아니라 **약속**입니다. 그래서 갈 주소가 없습니다.

- 남과 겨루지 않는다 — 랭킹 화면이 **없습니다**
- 말을 걸지 않는다 — 커뮤니티를 뒀다가 **걷어냈습니다**
- 광고가 없다
- 지어내지 않는다 — 칼로리 · 체지방률을 **추정하지 않습니다**
- 읽는 일은 폰 안에서 끝난다 — 사진 · 소리 · 영상이 **서버로 안 갑니다**
  (견주기용 사진만 계정에 저장되고, `/body` 에서 지울 수 있습니다)

### 「지하에서도」

> *신호가 끊기면 적은 것을 폰에 담아뒀다가 올라와서 저절로 올린다*

화면이 아니라 **앱 전체가 그렇게 동작합니다.** 「운동」에서 세트를 적을 때 신호가
없으면 폰에 쌓아뒀다가 신호가 오면 올립니다. 같은 기록이 두 번 올라가지 않습니다.

### 「시작하기」

**→ `/register`** (가입하기) · **`/login`** (로그인)

## 「몸」 탭 안의 다섯 갈래

`/body` 하나에 다 들어 있습니다. 홈페이지에서 말하는 기능 중 둘이 여기 있습니다.

| 갈래 | 무엇 |
|---|---|
| **인바디** | 체중 · 골격근량 · 체지방 기록 |
| **재는 도구** | 줄자로 잰 둘레 |
| **견주기** | 사진 두 장을 겹쳐 봅니다 |
| **체형** | 사진에서 잰 비율로 실루엣을 다시 그립니다 |
| **회복** | 동작 뒤 숨이 가라앉는 데 걸린 초 |

옛 주소 `/inbody` · `/measure` 로 들어와도 **그 갈래로 넘겨줍니다** (북마크가 살아 있게).

## 「기록」 탭 안의 세 갈래

| 갈래 | 무엇 |
|---|---|
| **달력** | 날짜별로 뭘 했나 |
| **기록의 벽** | 한 해를 금속판 열두 장에 새깁니다 |
| **통계** | 늘었나 줄었나 |

---

## 옛 주소는 안 죽입니다

북마크 · 폰 홈 화면 바로가기 · 옛 PWA 캐시가 그 주소로 옵니다.
**주소는 살려두고 지금 그 일을 하는 자리로 넘깁니다.**

| 옛 주소 | 가는 곳 |
|---|---|
| `/workout` | `/train` |
| `/inbody` | `/body` (인바디 갈래) |
| `/measure` | `/body` (재는 도구 갈래) |
| 그 밖에 없는 주소 | `/home` |

## 로그인 쪽

| | 주소 | 메모 |
|---|---|---|
| 로그인 | `/login` | 구글 · 네이버 단추가 여기 있습니다 |
| 회원가입 | `/register` | 두 걸음 — ① 메일 확인 ② 계정 만들기 |
| 메일 묻는 걸음 | `/oauth/email` | **지금은 안 쓰입니다.** 인스타 · X 를 켜는 날 살아납니다 |
