# 어디가 느린가 — 재본 값 (2026-09-18)

```
cd backend && npm run bench          사람 1명 · 5년치
cd backend && npm run bench -- 10    사람 10명을 같이 넣고
```

**짐작으로 고치지 않으려고 만든 자리다.** 이 앱에서 여태 잡은 느린 자리는 전부
재본 뒤에 드러났고, 재고 나면 고칠 자리가 대개 한 줄이었다.

검사가 아니다 — 통과·실패가 없다. 수를 적어두고 **다음에 견준다.**
기계마다 다르므로 아래 값은 「이 PC 에서 2026-09-18 에」 잰 것이다.

## 오늘 이 값을 보고 고친 것

**하루치 조회가 표 전체를 훑고 있었다** (`db.getWorkoutsByDate`) — 모든 사람의 모든 줄을
훑어 걸렀다. 내 목록은 이미 표에 들고 있으므로(5초) 거기서 걸러내면 **남의 줄은 아예 안 본다.**

```
3.28 ms  →  0.48 ms      (같은 자료, 사람 10명 · 29만 줄)
```

달력이 날마다 부르는 자리라 한 달이면 서른 번이다 — 100ms 가 15ms 가 된다.

## 2026-09-19 에 밝혀진 것 — **이 표의 한 줄은 헛것이었다**

위의 「하루치만 (달력이 날마다 부른다) 3.28ms → 0.48ms」는 **아무도 부르지 않는 길을
빠르게 만든 것이었다.** 9/19 에 앱이 부르는 주소와 서버가 가진 주소를 맞춰 보니
`GET /api/workouts/:date` 를 앱이 **한 번도 안 부른다** — 앱은 목록을 통째로 받아
들고 있고(`workoutStore`) 달력도 거기서 걸러 쓴다. 그 길과 DB 함수를 걷었다.

**재기 전에 「누가 부르는가」를 먼저 봐야 한다.** 자를 만든 것은 옳았는데, 자가 가리킨
자리 중 하나가 아무도 안 지나는 자리였다. 이제 `cd backend && npm run api` 가
양쪽을 맞춰 본다 — 없는 길을 부르는 자리도, 아무도 안 부르는 길도 같이 잡는다.

## 9/19 에 이 표를 보고 고친 것

**3번은 미루지 않았다.** 이유가 두 가지였다 —

- 위 표의 첫 줄(저장 173ms)은 「느리다」가 아니라 **그동안 서버가 아무 요청도 못 받는다**
  는 뜻이었다. DB 이사는 언제 할지 안 정한 일이고, 그때까지 그 멈춤을 그대로 두는 것과
  다르다
- **쓰다 죽으면 기록 전부가 사라지는 길**이 그 안에 같이 있었다. 그건 속도가 아니다

| 무엇 | 전 | 후 |
|---|---|---|
| 저장할 때 **서버가 멈추는 시간** | 173 ms | 205 ms(문자열) — **파일 쓰기 189ms 는 비동기** |
| 저장한 뒤 첫 조회 (실제로 겪는 값) | 10.5 ms | **6.8 ms** (사람별 색인) |
| 하루치만 (달력이 날마다 부른다) | 3.28 ms | **0.62 ms** |
| 날짜 정렬 (29,200줄) | 29.1 ms | **4.3 ms** (`localeCompare` → 그냥 비교) |
| 표에 있을 때 | 0.001 ms | 0.12 ms — **사본을 주기 때문이다** (아래) |

**마지막 줄은 일부러 느려진 것이다.** 표가 담아둔 배열을 그대로 돌려주고 있었다 —
받은 쪽이 한 번 `sort` 하면 표가 오염되고 5초 동안 모두가 그것을 본다.
가리키는 것만 베껴 주는 값이 0.12ms 고, 다시 훑는 10.5ms 보다 백 배 싸다.

**남은 1·2번(DB 이사 · 사진)은 그대로다.** 저장 한 번이 여전히 파일 한 장 전체고,
힙 뚜껑에 닿는 사람 수도 그대로다 — 「배포하자」 할 때 함께 정한다.
고친 것은 `npm run save` 로 못을 박아뒀다.

## 재는 자리를 늘릴 때

`backend/scripts/bench.cjs` 에 한 줄 더하면 된다. 다만 두 가지는 지킨다 —

- **진짜 DB 를 안 건드린다** (`DB_FILE` 로 임시 파일을 쓰고 지운다)
- **글자를 돌려쓰지 않는다.** 사진을 잴 때 같은 글자를 서른 번 넣었더니 자바스크립트가
  하나만 들고 있어서 메모리가 1.4MB 밖에 안 늘었다 — 하마터면 「사진은 가볍다」로
  읽을 뻔했다. 사람마다 다른 자료라야 진짜 값이 나온다
