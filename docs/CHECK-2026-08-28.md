# 확인 목록 (2026-08-28 에 바꾼 것)

오늘은 **색**을 바꿨다. 색은 눈으로 보면 「예쁘다」로 끝나서, 안 보이는 글자를
그냥 지나친다. 그래서 기계가 볼 수 있는 것은 전부 기계에 넘겼고,
**사람이 봐야 하는 것만** 여기에 남긴다.

먼저 이것부터.

```bash
cd frontend && npm run check      # 계산 + 색 대비 11 + 그래프 색 = 토큰 9
cd backend  && npm run check      # 알림 (시간대 · 몇 번 보내나)
cd backend  && npm start          # (다른 창)
cd backend  && npm run smoke      # 한 바퀴 + 화면이 기대하는 모양 14 + 관리자만 6
```

전부 통과해야 한다. 하나라도 FAIL 이면 아래를 볼 것도 없다.

## 1. 눈으로 봐야 하는 것

### 검정과 금 (`--accent` = `#eeb77d`)

- **배경이 평면이 아니다** — 위쪽이 살짝 밝고 금빛이 돈다. 아래로 갈수록 가라앉는다
- **카드 윗변에 금실 한 줄** — 카드마다 위쪽 모서리에 아주 얇은 금빛 선
- **큰 단추는 금으로 통째로 칠해져 있지 않다** — 어두운 바탕 + 금 테두리 + 금 글자
- 탭바의 지금 탭이 금, 빨간 숫자 딱지는 **진한 빨강**(밝은 빨강에 흰 글자는 안 보인다)
- 홈 화면에 추가(PWA)로 깔면 **아이콘이 금색**이다. 예전에 깔아뒀다면 빨간 아이콘이
  남아 있을 수 있다 — 지웠다 다시 깐다

### 그래프

두 번 바뀌었다. 색이 원래부터 안 먹고 있던 것을 고쳤고(축 글씨가 검정이라 안 보였다),
그다음 **recharts 를 걷어내고 직접 그렸다.**

> **8/31 덧붙임 — 그리는 것까지는 기계가 본다.** 「브라우저에서만 확인된다」고 적어뒀는데,
> 그리는 쪽은 화면 없이도 돌려볼 수 있었다. `npm run check` 에 **네 개를 실제로 그려서**
> SVG 를 읽는 검사 열여덟을 넣었다 — 축 글자 색이 전부 토큰인지, 안 잰 날에서 선이
> 끊기는지, 막대 밑동이 0 에 붙어 있는지, 조각이 넷인지, 축 이름 다섯이 다 적히는지.
> 그래서 **아래에서 눈으로 볼 것은 「값이 맞는가 · 겹치지 않는가」뿐이다** —
> 글자가 서로 겹치는 것과 말풍선(짚기)은 여전히 브라우저에서만 보인다.

시연 계정으로 보면 데이터가 있다 — **seed@demo.local / seed12345**
(없으면 `cd backend && npm run seed`).

인바디 화면:

1. **체중 추이** — 금색 선. **축의 날짜와 숫자가 보인다.** 선 위를 마우스로
   훑거나 손가락으로 짚으면 아래에 「08-14 — 체중 72.6kg」이 뜬다
2. **체지방/골격근 추이** — 빨강 · 초록 두 선 + 아래 범례. 값이 없는 날은 **선이 끊긴다**
3. **체성분 도넛** — 골격근 초록 · 체지방 빨강 · 체수분 파랑 · 기타 회색.
   가운데에 몸무게 합이 적혀 있다

비교 화면:

4. **막대** — 회색(과거) · 금색(현재)이 나란히. **막대가 0 에서 시작한다.**
   막대 위를 짚으면 「72.6 → 71.2」가 뜬다
5. **오각형** — 두 겹. 축마다 이름과 「과거 → 현재」가 적혀 있고,
   그림 아래에 「축마다 눈금이 따로」라는 한 줄이 있다

**세로 눈금이 이상하면**(71.33 같은 숫자, 또는 눈금이 값보다 좁으면)
`npm run check` 의 「그래프 눈금」이 먼저 잡아준다 — 거기가 통과인데 화면이
이상하면 그리는 쪽(`components/charts/`)이다.

폰에서도 한 번 본다 — 가로가 좁으면 날짜를 몇 칸씩 건너뛰어 적는다.

## 3. 겪기 어려운 것 (돼 있다는 것만)

| 무엇 | 어떻게 확인하나 |
|---|---|
| 서버가 배열 대신 다른 모양을 주면 | `npm run smoke` 의 「화면이 기대하는 모양대로 오는가」가 잡는다 |
| 색 토큰을 고치고 그래프를 잊으면 | `frontend npm run check` 의 「그래프 색 = 토큰」 아홉 쌍이 잡는다 |
| 그래프가 그리다 터지거나 조용히 비면 | 같은 검사의 「그래프를 그려본다」 열여덟이 잡는다 (8/31 에 넣음) |
| 안 잰 날을 이어 그려서 잰 것처럼 보이면 | 같은 검사의 「안 잰 날에서 선이 끊긴다」가 잡는다 |
| 그래프 눈금이 이상해지면 | 같은 검사의 「그래프 눈금」 아홉 가지가 잡는다 |
| 금을 밝게 해서 그 위 흰 글자가 죽으면 | 같은 검사의 「색 대비」 열하나가 잡는다 |
| DB 파일 이름이 바뀌었다 | `backend/steelbody.json` (옛 이름 `ironlog.json`). 서버를 내리고 옮겼다 |
