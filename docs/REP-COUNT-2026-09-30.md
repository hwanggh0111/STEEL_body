# 횟수 세기 — 폰을 옆에 두면 대신 센다 (2026-09-30)

체형에 붙인 자세 인식(`data/poseModel.js`, 9/22)이 이미 관절 33점을 잡는다. 스쿼트는
무릎이, 푸시업은 팔꿈치가 **접혔다 펴지면 한 번**이다. 세트 중에 숫자를 세는 일에서
사람을 놓아준다.

> 폰을 옆에 세워두고 운동한다. 관절이 오간 횟수를 세서 **횟수 칸에 넣는다.**
> 저장은 사람이 누른다.

## 아는 것과 모르는 것

- **아는 것** — 관절 각도가 오간 횟수. **그것뿐이다.**
- **모르는 것** — 자세가 옳은지 · 깊이가 충분한지 · 무게가 맞는지. **말하지 않는다.**
  「무릎이 안쪽으로 모였어요」 같은 말은 옆에 둔 폰 한 대가 알 수 있는 것이 아니다.
  그걸 적으면 짐작을 코치로 내놓는 것이고, 체형에서 거절한 바로 그것이다.

## 정한 것

### 1. 이름으로 관절을 고른다 — 모르면 **안 연다**

부위로는 못 고른다(벤치프레스와 플라이는 같은 부위인데 하나는 팔꿈치가 접히고 하나는
거의 안 접힌다). 그래서 이름으로 고른다.

| 갈래 | 보는 관절 | 화면이 하는 것 |
|---|---|---|
| 스쿼트 · 런지 · 버피 · 점프스쿼트 … | **무릎** | 센다 |
| 푸시업 · 벤치프레스 · 딥스 · 풀업 · 컬 … | **팔꿈치** | 센다 |
| 플랭크 · 월싯 · 홀드 | (없음) | **「버티는 운동은 셀 것이 없어요」** |
| 사전에 없는 이름 | (모름) | **「이 운동은 아직 셀 수 없어요」** |

**버티는 것과 모르는 것을 가른다** — 사람이 할 수 있는 일이 다르다. 그리고 두 경우 다
**단추를 아예 안 낸다**: 플랭크 옆에 「세어줄까요」가 있으면 눌러보고 0 을 보게 된다.

### 2. 떨림을 안 센다 — 막는 것은 **둘**이다

- **문턱 사이 55도** — 하나로 세려면 접힘(100도)과 펴짐(155도)을 둘 다 넘어야 한다.
- **하나와 다음 하나 사이 600ms** — 그보다 빠른 것은 사람이 아니라 떨림이다.

> 처음에는 「이만큼은 움직여야 한다」(`MIN_RANGE = 25`)를 따로 뒀는데 **한 번도 걸릴 수
> 없는 규칙**이었다 — 문턱 둘이 이미 55도를 요구한다. 검사가 그것을 잡아서 걷어냈다.
> 죽은 규칙을 두면 「폭도 본다」고 믿게 된다 (9/29 에 위조 토큰 규칙이 세는 데 없이
> 이름만 있던 것과 같은 자리다).

### 3. 켜자마자 1이 되지 않게

이미 앉아 있던 사람이 일어서는 것을 세면 카메라를 켠 순간 숫자가 올라간다.
**펴진 데에서 들어온 접힘**만 하나로 센다(`fromUp`).

그리고 **첫 하나에는 600ms 를 안 본다** — 그 자는 「하나와 다음 하나 사이」의 것이다.

### 4. 못 본 것은 못 본 것이다

관절이 안 보이면 `null` 이고, **0도로 읽지 않는다.** 0도는 「완전히 접혔다」는 뜻이라
그대로 두면 **안 보이는 순간마다 한 번씩** 세어진다. 못 본 프레임이 절반을 넘으면
화면이 먼저 그 말을 한다 — 숫자가 안 올라가는 까닭이 「내가 잘못하고 있나」가 아니라
**카메라에 안 들어온 것**일 때가 많다.

### 5. 영상은 아무 데도 안 남는다

프레임을 모델에 넘기고 버린다. 녹화하지 않고(`MediaRecorder` 를 안 쓴다), 어디로도
보내지 않는다 — **나가는 것은 숫자 하나**다. 닫으면 그 자리에서 트랙을 멈춘다(탭의
촬영 표시가 바로 사라져야 꺼진 것을 안다 — `useBreath` 가 마이크에 두는 규칙과 같다).

### 6. 저장은 사람이 누른다

세고 나서 **횟수 칸만 채운다.** 목소리로 적기와 같은 규칙이다 — 세는 것도 틀릴 수 있고,
바로 저장하면 틀린 기록이 조용히 쌓인다. 0 이면 칸을 아예 안 건드린다.

## 만든 것

| 자리 | 무엇 |
|---|---|
| `frontend/src/data/repCount.js` | 새로 — 관절 고르기 · 각도 · 세는 기계 (**카메라도 화면도 모른다**) |
| `frontend/src/data/poseModel.js` | 영상 모드(`loadPoseVideo` · `readPoseFrame`) — 사진용과 **따로** 만든다 |
| `frontend/src/components/RepCounter.jsx` | 새로 — 카메라를 켜고 큰 숫자를 보여준다 |
| `frontend/src/pages/TrainPage.jsx` | 「횟수를 세어줄까요?」 (목소리로 적기와 같은 자리) |
| `frontend/scripts/check-reps.cjs` | 값으로 본다 46건 (`npm run reps`) |

모델은 **영상용을 따로 만든다.** 하나에 두 모드를 겹쳐 쓸 수 없고, 모드를 바꿔 끼우면
체형이 쓰던 것과 서로 빼앗는다. wasm 과 모델 파일은 브라우저가 이미 캐시에 들고
있으므로 두 번째 것의 값은 **내려받기가 아니라 만드는 값**뿐이다.

## 안 할 것

- 자세 · 깊이 · 좌우 균형을 평하기 (**코치 노릇**)
- 영상을 저장하거나 보내기
- 센 것을 **바로 저장**하기
- 셀 수 없는 운동에 단추를 내놓고 0 을 보여주기
